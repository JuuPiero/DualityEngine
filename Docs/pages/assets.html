API Reference

Asset Pipeline

Mọi asset (texture, âm thanh, Material, Prefab, ScriptableObject, Scene) đi qua một quy ước GUID/.meta chung kiểu Unity/Unreal — tham chiếu asset qua GUID ổn định, không phải đường dẫn dễ vỡ khi đổi tên/di chuyển file.

GUID & .meta

File đầu tiên được Content Browser nhìn thấy sẽ tự sinh một <tên file>.meta cạnh nó (JSON, GUID 32 hex ngẫu nhiên) — AssetMeta::EnsureMetaFile, gọi mỗi frame Content Browser liệt kê thư mục nhưng chỉ ghi file khi chưa tồn tại (rẻ). File .meta tự ẩn khỏi lưới Content Browser (bookkeeping, không phải asset để chọn).

struct AssetRef { std::string Guid; }

Kiểu field reflection dùng cho mọi tham chiếu asset (texture, Material, Mesh, Prefab, âm thanh...) — Guid rỗng nghĩa là "chưa gán". Dùng trực tiếp được với MakeField<C,T>() như mọi kiểu field khác, không cần dựng riêng.

class AssetDatabase { static std::string ResolvePath(guid); static void Register(guid, path); }

Bảng ánh xạ GUID ↔ đường dẫn thật trên đĩa, nạp lại khi mở project/khi Content Browser duyệt qua thư mục.

Dispatch theo extension qua AssetInspectorRegistry (chỉ ở phía Editor) — cùng cách TypeRegistry dispatch component theo Entity, chỉ khác là dispatch theo file. Thêm loại asset mới chỉ cần một entry {Extension, DisplayName, DrawInspector}, không sửa Properties panel.

Prefab

Unity's Prefab — một entity + toàn bộ subtree con, lưu thành file .prefab tái dùng được.

  • Tạo: chuột phải một entity trong Hierarchy → Create Prefab from Selection (ghi ra Assets/Prefabs/<Tên>.prefab).
  • Đặt vào scene: kéo file .prefab từ Content Browser thả vào khoảng trống Hierarchy, hoặc gọi Behaviour::Instantiate(guid) từ script.
Chưa có link ngược về prefab gốc — một bản instantiate là entity độc lập hoàn toàn sau đó, không có Apply/Revert như Unity.

ScriptableObject

Data asset tái dùng, không gắn Entity nào — giống Unity's ScriptableObject.

// GameSettingsData.h -- ví dụ có sẵn trong repo
class GameSettingsData : public Duality::ScriptableObject {
public:
    float PlayerSpeed = 200.0f;
    float ScorePerCoin = 10.0f;
    std::string GameTitle = "My Game";

    static std::vector<Duality::FieldHandle> Fields() {
        return {
            MakeField("Player Speed", &GameSettingsData::PlayerSpeed),
            MakeField("Score Per Coin", &GameSettingsData::ScorePerCoin),
            MakeField("Game Title", &GameSettingsData::GameTitle),
        };
    }
};
REGISTER_SCRIPTABLE_OBJECT(GameSettingsData) // thay vì REGISTER_BEHAVIOUR

Tạo instance qua Content Browser: chuột phải → Create → ScriptableObject → GameSettingsData. Đọc từ script qua LoadScriptableObject<T>(guid) (xem Scripting API).

Không dùng DUALITY_PROPERTIES ở đây (macro đó cho Behaviour) — ScriptableObject dùng quy ước static Fields() hand-written gốc, có trước DUALITY_PROPERTIES và vẫn được giữ nguyên không migrate.

Import Settings

Lưu trong .meta của chính asset (dưới key "Importer", cạnh "guid") — vì .png/.wav là định dạng nhị phân ngoại lai engine không sở hữu, không thể nhét field riêng vào file gốc.

struct TextureImportSettings { FilterMode FilterMode; WrapMode WrapMode; bool GenerateMipmaps; }

FilterMode: Point/Bilinear. WrapMode: Clamp/Repeat. Desktop áp dụng FilterMode/WrapMode ngay lúc chỉnh (reload texture cache); 3DS chỉ nhận thay đổi sau khi bấm lại Build for 3DS. Mipmap được "bake" lúc build (cờ -m box của tex3ds), không phải runtime.

struct AudioImportSettings { float Volume; }

Đúng một field — cố ý, vì đây là setting duy nhất có hành vi engine thật để gắn vào (không âm lượng nào tồn tại trước khi field này được thêm).

Content Browser

Duyệt <project>/Assets/ dạng lưới icon, thumbnail thật cho ảnh.

  • Click 1 lần — chọn (hiện Inspector ở Properties). Bắt trên mouse-release, không phải mouse-down — bắt đầu kéo một asset để thả vào field không còn tự chọn lại nó nữa.
  • Double-click — vào thư mục, hoặc mở trực tiếp một file .scene làm scene đang chạy.
  • Kéo ra — thả vào field AssetRef ở Properties để gán (theo GUID); thả vào icon thư mục để di chuyển file.
  • Kéo file từ Explorer vào — import vào thư mục đang mở.
  • Chuột phải khoảng trống — Create → Folder/Scene/Material/ScriptableObject → <Type>.
  • Chuột phải một file/folder — Rename (Enter/click-ra-ngoài lưu, Esc huỷ) / Delete (có xác nhận, không Recycle Bin).

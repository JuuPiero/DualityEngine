Làm game đầu tiên

Dựng một mini-game hoàn chỉnh từ Editor trống: nhân vật di chuyển bằng vật lý, một vật để "nhặt" bằng trigger, phản hồi qua Console/UI, và chuyển sang scene thứ hai khi thắng — rồi build ra máy 3DS thật. Giả định đã build Editor thành công (xem Cài đặt & Build).

  1. Tạo entity Player

    Trong panel Hierarchy, bấm Create Entity, đổi tên (field Name trong Properties) thành Player. Bấm + Add Component → Sprite Renderer, chỉnh Size thành (32, 32) và Color tuỳ ý. Kéo một ảnh từ Content Browser vào field Texture nếu muốn (không bắt buộc — không có texture thì vẫn hiện ô màu đặc).

  2. Thêm vật lý cho Player

    + Add Component → Rigidbody 2D (giữ Body Type = Dynamic), rồi + Add Component → Box Collider 2D, chỉnh Size khớp với sprite (nửa-kích-thước, vd (16, 16)). Thêm một entity Ground khác với Sprite Renderer (kéo dài ra làm nền) + Rigidbody 2D (Body Type = Static) + Box Collider 2D để Player đứng lên trên.

    Trục Y trong engine này tăng dần xuống dưới (khớp quy ước renderer) — trọng lực dương nghĩa là "rơi xuống", không phải âm như convention vật lý thường thấy.
  3. Viết script di chuyển

    Tạo GameScripts/Include/PlayerMoveBehaviour.h:

    #pragma once
#include "DualityEngine/Scene/Behaviour.h"

class PlayerMoveBehaviour : public Duality::Behaviour {
public:
    void OnUpdate(float deltaTime) override;

    // Field này hiện trong Properties panel nhờ DUALITY_PROPERTIES bên dưới
    float Speed = 150.0f;

    DUALITY_PROPERTIES(PlayerMoveBehaviour, Speed)
};

    Và GameScripts/Source/PlayerMoveBehaviour.cpp:

    #include "PlayerMoveBehaviour.h"
#include "ScriptRegistration.h"

void PlayerMoveBehaviour::OnUpdate(float deltaTime) {
    float h = GetAxis("Horizontal"); // WASD/mũi tên desktop, Circle Pad 3DS
    SetVelocity2D({ h * Speed, GetVelocity2D().y }); // giữ nguyên Y để trọng lực vẫn hoạt động

    if (GetKeyDown(Duality::KeyCode::Space) || GetKeyDown(Duality::KeyCode::GamepadA))
        AddForce2D({ 0.0f, -12000.0f }); // nhảy -- Y âm = hướng lên
}

REGISTER_BEHAVIOUR(PlayerMoveBehaviour)

    Thêm 2 file vào GameScripts/CMakeLists.txt (cạnh các entry có sẵn), gắn PlayerMoveBehaviour vào field Class của + Add Component → Behaviour trên entity Player, rồi bấm Reload Scripts (toolbar panel Game).

  4. Tạo vật để nhặt (trigger)

    Tạo entity Coin — Sprite Renderer (màu vàng) + Circle Collider 2D với Is Trigger bật (không cần Rigidbody — một collider tĩnh không Rigidbody vẫn hoạt động như static). Script nhặt, CollectCoinBehaviour.h/.cpp: 

    #pragma once
#include "DualityEngine/Scene/Behaviour.h"

class CollectCoinBehaviour : public Duality::Behaviour {
public:
    void OnTriggerEnter(Duality::Entity other) override;
};
    #include "CollectCoinBehaviour.h"
#include "DualityEngine/Scene/Components.h"
#include "ScriptRegistration.h"

void CollectCoinBehaviour::OnTriggerEnter(Duality::Entity other) {
    // Chỉ phản ứng khi đúng Player chạm vào (kiểm tra bằng Name -- đơn giản, đủ dùng ở quy mô này)
    if (other.GetComponent<Duality::NameComponent>().Name != "Player")
        return;
    LogInfo("Nhặt được coin!"); // hiện trong panel Console
    SetActive(false); // biến mất khỏi Scene view + Game view ngay lập tức
}

    Gắn script này vào entity Coin, thêm file vào CMakeLists, Reload Scripts.

    Cả hai phía của một cặp chạm đều nhận callback — script đặt ở Coin hay Player đều được, chỉ cần đúng một bên có OnTriggerEnter.
  5. Thử ngay trong Editor

    Bấm Play (panel Game). Dùng WASD/mũi tên di chuyển, Space nhảy, chạm vào Coin để thấy nó biến mất và dòng log hiện trong Console. Bấm Stop — scene tự động quay về đúng trạng thái trước khi Play (Coin xuất hiện lại), không cần Save/Load thủ công.

  6. Tạo màn thắng và chuyển scene

    Content Browser → chuột phải → Create → Scene, đổi tên thành WinScreen.scene, double-click để mở nó, thêm một entity WinLabel với Sprite Renderer màu nổi bật để biết đã sang scene mới thành công. Save Scene, rồi mở lại scene gốc (Content Browser, double-click file scene ban đầu).

    Sửa CollectCoinBehaviour::OnTriggerEnter để chuyển scene thay vì chỉ ẩn:

    void CollectCoinBehaviour::OnTriggerEnter(Duality::Entity other) {
    if (other.GetComponent<Duality::NameComponent>().Name != "Player")
        return;
    LogInfo("Thắng!");
    LoadScene("WinScreen.scene"); // đường dẫn tương đối Assets/ -- xử lý ở frame kế tiếp, không ngay lập tức
}
    LoadScene là request hoãn lại (deferred) -- code chạy sau lời gọi này trong cùng OnUpdate vẫn còn thấy scene cũ, vì việc chuyển scene diễn ra giữa hai frame, không đồng bộ ngay khi gọi.
  7. Build ra máy 3DS thật

    Menu File → Build for 3DS (xem Cài đặt & Build để biết chi tiết .3dsx/.cia). Toàn bộ vật lý, script, chuyển scene chạy y hệt trên máy thật/Citra như trong Editor — cùng một pipeline Scene/SceneSerializer, chỉ khác renderer backend (citro2d/citro3d thay vì OpenGL).

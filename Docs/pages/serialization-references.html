Serialization & References

Quy tắc lưu dữ liệu game an toàn qua Save/Load Scene, duplicate prefab, Play/Stop và script reload. Dùng reference ổn định; không giữ raw pointer của ECS hay asset.

Quy tắc ngắn gọn Nếu dữ liệu sống trong Project/Assets, dùng AssetRef. Nếu nó sống trong Scene, dùng EntityRef. Component và Behaviour luôn được tìm lại từ Entity ở runtime.

Ví dụ: FruitConfigSO trong GameManager

Không khai báo FruitConfigSO theo value. Điều đó vừa không nằm trong danh sách kiểu field reflection, vừa tạo một bản copy dữ liệu vào từng instance GameManager. Config là một asset dùng chung nên script chỉ lưu GUID của asset.

#include "DualityEngine/Scene/Behaviour.h"
#include "DualityEngine/Scripting/ScriptScene.h"
#include "FruitConfigSO.h"

class GameManager : public Duality::Behaviour {
public:
    DUALITY_PROPERTY() Duality::AssetRef FruitConfig;
    DUALITY_PROPERTIES_AUTO()

private:
    FruitConfigSO* m_FruitConfig = nullptr;

public:
    void OnCreate() override {
        m_FruitConfig = Duality::ScriptScene::LoadScriptableObject<FruitConfigSO>(FruitConfig.Guid);
        if (!m_FruitConfig) {
            LogError("GameManager: FruitConfig asset is not assigned or cannot load");
            return;
        }
    }
};
  1. Tạo FruitConfigSO.asset từ Content Browser → Create → ScriptableObject → FruitConfigSO.
  2. Gắn GameManager vào Entity.
  3. Kéo file .asset vào field Fruit Config trong Inspector.
  4. Ở runtime, kiểm tra m_FruitConfig trước khi đọc NormalSprites hoặc OutlineSprites.
Không cache FruitConfigSO* qua Reload Scripts. Nhận lại pointer trong OnCreate(); field AssetRef mới là dữ liệu bền vững được serialize.

Entity, component và script

Một component không có GUID riêng và địa chỉ/pointer của nó sẽ thay đổi khi scene được load lại. Vì vậy Inspector kéo thả Entity, không kéo thả raw component.

class Fruit : public Duality::Behaviour {
public:
    DUALITY_PROPERTY() Duality::EntityRef Tree;
    DUALITY_PROPERTIES_AUTO()

    void OnUpdate(float dt) override {
        Duality::Entity tree = ResolveEntityRef(Tree);
        if (!tree) return;

        if (auto* transform = tree.TryGetComponent<Duality::TransformComponent>()) {
            // Đọc component an toàn sau khi entity được resolve.
        }
    }
};

EntityRef được serializer đổi sang index trong file scene khi save, sau đó đổi lại Entity handle mới sau khi toàn bộ scene được tạo lại. Một reference rỗng hoặc entity đã bị xoá sẽ resolve thành Entity rỗng, vì vậy luôn kiểm tra if (entity).

Kiểu được DUALITY_PROPERTY hỗ trợ

Hiện có scalar (int, float, bool, std::string), glm::vec2/vec3/vec4, màu, engine enum, AssetRef, EntityRef, list std::vector<AssetRef>/std::vector<EntityRef> và struct với DUALITY_SERIALIZABLE(). Type C++ bất kỳ, raw pointer, Entity hoặc Component* không phải field type hợp lệ.

Vòng đời và an toàn trên 3DS

  • Chỉ giữ raw pointer SO/component trong một lượt runtime; lấy lại từ reference ở OnCreate() sau mỗi Play hoặc reload script.
  • Giữ config lớn trong ScriptableObject để không nhân bản dữ liệu theo từng entity, giảm RAM/VRAM pressure trên 3DS.
  • Không lưu path vào scene. AssetRef.Guid sống sót khi asset được rename hoặc move vì .meta giữ GUID.
  • Không dùng entity reference để liên kết sang scene khác; chỉ reference asset mới phù hợp xuyên scene.

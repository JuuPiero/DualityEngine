API Reference

Scripting API (Behaviour)

Mọi gameplay code kế thừa Duality::Behaviour — C++ thuần, không ngôn ngữ script nhúng. Build thành DLL hot-reload trên desktop (Reload Scripts, không cần khởi động lại Editor), link tĩnh vào DualityPlayer trên 3DS — cùng một bộ source, không sửa code giữa hai nền tảng. Mọi method dưới đây gọi được từ bất kỳ lifecycle nào bên trong một Behaviour subclass.

Vì sao API đi qua EngineServices? Trên desktop, GameScripts.dll không link compiled code của DualityEngine (chỉ header — tránh 2 bản sao độc lập của mọi static/registry, gây desync). Nên mọi lời gọi chạm tới code đã compile (Input, Audio, Box2D/Bullet, TypeRegistry...) phải đi qua EngineServices — một struct con trỏ hàm C-ABI thuần (int, const char*, void*, không kiểu engine/STL nào lộ ra ABI) được Scene gán cho mỗi Behaviour ngay sau khi tạo. Các method dưới đây là lớp wrapper tiện dùng bọc quanh cầu nối đó — bạn không bao giờ gọi EngineServices trực tiếp.

Vòng đời (Lifecycle)

MethodKhi nào chạy
OnCreate()Một lần khi Play bắt đầu (giống Awake Unity) — chạy kể cả khi entity bắt đầu ở trạng thái inactive.
OnEnable() / OnDisable()Mỗi khi Scene::IsEffectivelyActive của entity đổi trạng thái (do chính nó gọi SetActive, hoặc do cha đổi) — có thể chạy nhiều lần trong một lần Play.
OnUpdate(float deltaTime)Mỗi frame, chỉ khi đang active.
OnCollisionEnter(Entity other) / OnCollisionExit(Entity other)Cặp collider chạm/rời nhau, không bên nào IsTrigger. Cả 2D và 3D dùng chung callback này.
OnTriggerEnter(Entity other) / OnTriggerExit(Entity other)Giống trên, nhưng ít nhất một bên IsTrigger = true.
OnDestroy()Một lần lúc Stop — một instance vẫn active nhận thêm một OnDisable() cuối ngay trước đó.
Chưa có OnCollisionStay/OnTriggerStay (chạy mỗi frame trong lúc vẫn chạm) — chỉ có cạnh enter/exit ở phiên bản hiện tại.

Entity & Component

template<typename T> T& GetComponent()

Lấy component T trên entity đang sở hữu script này. Add/Has/Remove không expose trực tiếp trên Behaviour — dùng GetEntity().AddComponent<T>()/HasComponent<T>()/RemoveComponent<T>().

auto& transform = GetComponent<Duality::TransformComponent>();
transform.Rotation.z += 90.0f * deltaTime; // độ, không phải radian
Entity GetEntity() const

Entity đang sở hữu instance script này.

Trạng thái Active

void SetActive(bool active)

Unity's GameObject.SetActive. Chỉ đặt cờ của chính entity này — xem Scene::IsEffectivelyActive (kiến trúc) để biết cách trạng thái cascades qua parent chain. Không tự thêm/gỡ physics body giữa lúc Play — chỉ quyết định có body hay không lúc Play bắt đầu.

bool IsActive()

Cờ Active của riêng entity này (không cascades qua cha).

Input 2D3D

Phong cách Unity Input Manager cũ.

bool GetKey/GetKeyDown/GetKeyUp(KeyCode key)

GetKey: true mọi frame đang giữ. GetKeyDown/GetKeyUp: true đúng 1 frame khi nhấn/thả. KeyCode phủ phím desktop phổ biến (W/A/S/D, mũi tên, Space/Enter/Escape) và nút 3DS (GamepadA/B/X/Y/L/R, GamepadStart/Select, D-Pad) — keycode vô nghĩa trên nền tảng hiện tại luôn đọc là chưa nhấn, không phải lỗi.

if (GetKeyDown(Duality::KeyCode::Space)) { /* chỉ 1 lần ở frame nhấn */ }
float GetAxis(const std::string& axisName)

Chỉ nhận "Horizontal"/"Vertical" (không phải hệ mapping tuỳ chỉnh như Input Manager thật của Unity). Desktop: digital ±1 từ WASD/mũi tên. 3DS: analog thật từ Circle Pad — cùng code, giá trị phù hợp từng nền tảng.

bool GetPointerDown()
glm::vec2 GetPointerPosition()
Screen GetPointerScreen()

Chuột trên desktop, cảm ứng trên 3DS. GetPointerPosition() trả toạ độ pixel local theo màn mà GetPointerScreen() báo — Top (400×240) và Bottom (320×240) có vùng toạ độ trùng nhau nên bắt buộc phải kiểm tra GetPointerScreen() trước khi dùng vị trí. Trên 3DS luôn là Screen::Bottom (cảm ứng chỉ có ở đó — sự thật phần cứng). 

if (GetPointerDown() && GetPointerScreen() == Duality::Screen::Bottom) {
    glm::vec2 p = GetPointerPosition(); // toạ độ local trong khung 320x240
}

Audio

void PlaySound(const std::string& assetGuid, bool loop = false) const

assetGuid là GUID từ .meta của một asset .wav (giống field AssetRef bất kỳ). Đọc Volume từ AudioImportSettings của chính asset đó mỗi lần gọi — không có tham số volume riêng cho từng lần phát. Chỉ hỗ trợ WAV 16-bit PCM trên 3DS thật (không có decoder nào khác được vendor).

void StopAllSounds() const

Dừng mọi âm thanh đang phát (không chọn lọc theo asset).

Logging

void LogInfo/LogWarn/LogError(const std::string& message) const

Hiện trong panel Console của Editor y hệt mọi log line khác của engine, màu theo mức độ.

Scene transitions

void LoadScene(const std::string& assetsRelativePath) const

Unity's SceneManager.LoadScene. Đường dẫn tương đối tới thư mục Assets/ của project (vd "Scenes/Level2.scene" — tạo qua Editor's File → Save Scene As...).

Là request hoãn lại — việc chuyển scene diễn ra giữa hai frame, không đồng bộ ngay; code chạy sau lời gọi này trong cùng OnUpdate vẫn thấy scene cũ, vì script không thể an toàn tự phá huỷ chính Scene đang chạy nó giữa chừng.

Tìm entity theo tên/màn

Entity FindEntityInScreen(Screen screen, const std::string& name) const
Entity FindEntityInTopScreen/FindEntityInBottomScreen(const std::string& name) const

Tìm entity theo tên trong subtree của ScreenGroupComponent của màn đó (đệ quy qua children); fallback về tìm theo tên toàn scene nếu màn đó chưa có group nào gắn tag. Trả entity rỗng (falsy) nếu không thấy.

Prefab

Entity Instantiate(const std::string& prefabAssetGuid) const

Unity's Object.Instantiate — spawn một bản copy của asset .prefab làm root entity mới trong Scene của script này. Trả entity rỗng nếu guid không resolve được asset prefab hợp lệ.

ScriptableObject

template<typename T> T* LoadScriptableObject(const std::string& assetGuid) const

Unity's ScriptableObject — data container tái dùng, sống như một asset project (file .asset) thay vì lặp lại thành field trên mọi entity cần nó. T phải là type GameScripts-side cụ thể do caller cung cấp (engine chỉ trả void* ẩn kiểu qua ABI). Trả nullptr nếu guid rỗng/không resolve được hoặc class chưa đăng ký (GameScripts chưa được (re)load).

auto* settings = LoadScriptableObject<GameSettingsData>(mySettingsGuid);
if (settings) LogInfo("Player speed: " + std::to_string(settings->PlayerSpeed));

Rigidbody velocity/force 2D3D

Xem chi tiết BodyType/Collider ở trang Physics.

glm::vec2 GetVelocity2D() const · void SetVelocity2D(const glm::vec2& v) const · void AddForce2D(const glm::vec2& f) const
glm::vec3 GetVelocity3D() const · void SetVelocity3D(const glm::vec3& v) const · void AddForce3D(const glm::vec3& f) const

Unity's Rigidbody2D.velocity/Rigidbody.velocity/AddForce, thao tác trên Rigidbody2DComponent/Rigidbody3DComponent của chính entity này. Trả vector 0 (Get) hoặc no-op (Set/AddForce) nếu entity không có Rigidbody đúng chiều, hoặc Play chưa chạy.

Raycast 2D3D

RaycastHit2D Raycast2D(const glm::vec2& origin, const glm::vec2& direction, float maxDistance) const
RaycastHit3D Raycast3D(const glm::vec3& origin, const glm::vec3& direction, float maxDistance) const

Unity's Physics2D.Raycast/Physics.Raycast. Trả collider gần nhất trúng dọc tia. RaycastHit2D/RaycastHit3D có HitEntity rỗng (falsy) nếu không trúng gì — luôn kiểm tra if (hit) trước khi đọc Point/Normal/Distance. Chỉ hoạt động khi đang Play (cần physics world đang sống).

bool ScreenPointToRay3D(Screen screen, const glm::vec2& screenPoint, glm::vec3& outOrigin, glm::vec3& outDirection) const

Đổi một điểm pixel local của screen (vd GetPointerPosition()) thành tia world-space xuất phát từ camera Perspective chính của màn đó — dùng chung với Raycast3D để làm click/chạm-để-chọn vật thể 3D. Trả false nếu màn đó không có camera Perspective chính.

if (GetPointerDown() && GetPointerScreen() == Duality::Screen::Bottom) {
    glm::vec3 origin, direction;
    if (ScreenPointToRay3D(Duality::Screen::Bottom, GetPointerPosition(), origin, direction)) {
        Duality::RaycastHit3D hit = Raycast3D(origin, direction, 2000.0f);
        if (hit) LogInfo("Trung: " + hit.HitEntity.GetComponent<Duality::NameComponent>().Name);
    }
}

Xem ví dụ chạy thực tế: GameScripts/Source/RaycastDemoBehaviour.cpp (gắn vào entity "RaycastController" trong scene mẫu).

Entity ResolveEntityRef(EntityRef ref) const · static EntityRef MakeEntityRef(Entity entity)

Chuyển đổi giữa field EntityRef (kiểu field reflection cho "tham chiếu tới entity khác", gán qua kéo-thả entity từ Hierarchy vào Properties) và Entity thật dùng được. Không có kiểu "component reference" riêng — giữ một EntityRef rồi gọi ResolveEntityRef(ref).GetComponent<T>() để lấy đúng component cần, giống cách Unity's [SerializeField] GameObject hoạt động.

EntityRef không sống sót qua một lần Save/Load scene — luôn về "chưa gán" sau khi load lại, vì handle thô không ổn định qua reload (entity nhận handle mới theo thứ tự tạo). Hoạt động đúng trong một phiên Editor/Play.

Bắt đầu

Cài đặt & Build

Dựng môi trường build cho cả desktop (Editor) và Nintendo 3DS thật/Citra, rồi chạy thử ngay lần đầu.

Yêu cầu

Công cụDùng để
devkitPro (devkitARM r68+)Toolchain build 3DS: citro2d, citro3d, libctru, 3dstools, 3dslink.
MSYS2 mingw64 (đi kèm devkitPro hoặc cài riêng)Toolchain build desktop: g++, CMake, Ninja, GLFW, GLEW.
makerom.exe / bannertool.exeĐóng gói .cia (không bắt buộc — thiếu thì build vẫn ra .3dsx). Đặt vào Tools/, xem link trong README.md.
Citra (Nightly khuyến nghị)Chạy thử .3dsx/.cia không cần máy thật.
Vendor tự chứa EnTT, GLM, nlohmann/json, Dear ImGui, stb_image, miniaudio, Box2D, Bullet Physics đều được vendor sẵn dạng source trong Vendor/ — không cần tải thêm gì khác ngoài hai toolchain ở trên. GLFW/GLEW lấy từ package mingw64.

Build Editor (desktop)

# Từ thư mục gốc repo
build.bat   REM configure (nếu cần) + build -> build\DualityEditor\DualityEditor.exe
run.bat     REM chạy Editor

build.bat tự thêm mingw64 (đi kèm devkitPro) vào PATH và dùng Ninja nếu có sẵn. Editor mở project mẫu tại SampleProject/ ngay khi khởi động.

Chạy test suite

run-tests.bat   REM build.bat đã build sẵn Tests\DualityEngineTests.exe

Bộ test headless (không cần GUI) cho logic engine cốt lõi — ECS/Active-Disable, physics 2D/3D, collision/trigger, raycast, scene serialization, asset pipeline... Xem Tests/, chạy tự động trên mỗi push/PR qua .github/workflows/ci.yml.

Build cho 3DS

build-3ds.bat   REM luôn configure sạch từ đầu -> build-3ds\DualityPlayer\*.3dsx / *.cia
run-3ds.bat     REM chạy .3dsx trong Citra
Vì sao luôn clean build? Tổ hợp CMake + Make của devkitPro có bug tái lập được: reconfigure tại chỗ sau khi sửa CMakeLists.txt làm hỏng file dependency đã sinh ra ("multiple target patterns. Stop."). build-3ds.bat né lỗi này bằng cách luôn xoá sạch build-3ds\ trước khi cấu hình lại — chậm hơn một chút nhưng đáng tin cậy, và toàn bộ quá trình vẫn dưới một phút.

.3dsx dùng để chạy nhanh qua Homebrew Launcher hoặc 3dslink (đẩy qua mạng tới máy thật/Citra). .cia để cài qua FBI trên máy thật/CFW — cần makerom.exe/bannertool.exe trong Tools/, thiếu thì build vẫn chạy, chỉ bỏ qua bước đóng gói .cia.

Build ngay từ trong Editor

Menu File → Build for 3DS lưu scene rồi tự chạy build-3ds.bat ở nền (không block UI) — asset (texture...) được "cook" qua tex3ds, tìm tự động qua biến môi trường DEVKITPRO/registry/đường dẫn mặc định, không hardcode. File → Build for PC build lại DualityPlayerDesktop (không cần bước cook romfs, vì target này đọc thẳng Assets/ từ đĩa) — chạy qua run-desktop-player.bat.

Cấu trúc repository

DualityEngine/       Lõi dùng chung: ECS, Reflection, Scene, physics 2D/3D,
                     renderer interface + backend, UI, asset pipeline
DualityEditor/       Editor desktop (Dear ImGui)
DualityPlayer/       Runtime thực thi trên 3DS
DualityPlayerDesktop/ Runtime desktop độc lập, không Editor
GameScripts/         Code gameplay (Behaviour) -- DLL hot-reload desktop,
                     link tĩnh 3DS, chung 1 bộ source
Tests/               Test suite headless
Vendor/              Third-party dependencies (vendor sẵn dạng source)
SampleProject/       Project mẫu Editor mở khi khởi động
Docs/                Trang tài liệu này

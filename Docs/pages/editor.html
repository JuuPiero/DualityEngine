Editor Panels

Editor desktop dựng bằng Dear ImGui, layout dock kiểu Unity/Cocos Creator mặc định. Mở project cố định tại SampleProject/ khi khởi động — tạo project mới qua File → New Project..., hoặc mở project có sẵn qua File → Open Project..., chọn file .dproj.

Hierarchy

Liệt kê entity trong scene, phân theo Top Screen/Bottom Screen/Ungrouped (dựa theo ScreenGroupComponent gắn trên root). Click chọn entity. Create Entity tạo entity rỗng mới. Kéo-thả để reparent (thả lên node) hoặc đổi thứ tự anh em (thả vào khoảng giữa hai node). Chuột phải một entity: Create Child Entity, Create Prefab from Selection.

Properties

Hiện mọi component trên entity đang chọn — field hoàn toàn generic qua reflection (xem Kiến trúc), thêm component/field mới không cần sửa code Editor. Mọi entity có checkbox Active ngay cạnh Transform/Name/Tag. Component không bắt buộc có nút "..." để gỡ; nút + Add Component ở cuối liệt kê mọi loại chưa có trên entity.

Lock (kiểu Unity Inspector) — ghim panel vào entity/asset đang hiện, bỏ qua lựa chọn mới ở Hierarchy/Scene/Content Browser cho tới khi bỏ khoá. Ít cần thiết hơn từ khi Content Browser đổi cách bắt click sang mouse-release (không còn tự chọn lại khi bắt đầu kéo-thả asset) — nhưng vẫn hữu ích để ghim khi duyệt chỗ khác.

Script gắn qua + Add Component → Add Script — một submenu con liệt kê mọi class script đã đăng ký, chọn một class là gắn ngay. Danh sách này gộp chung script dùng riêng của project đang mở (Assets/Scripts/, tạo qua Content Browser's Create → Script — xem Asset Pipeline) lẫn script dùng chung cấp engine (GameScripts/Include/+Source/) — sau khi build, cả hai nằm chung một ScriptRegistry, không còn phân biệt được nguồn gốc ở đây. Một entity có thể mang nhiều script khác nhau cùng lúc (hoặc cùng một script nhiều lần), mỗi script hiện thành một card riêng trong mục Scripts của Properties, kèm field public đánh dấu DUALITY_PROPERTY() của riêng nó (xem Kiến trúc) và nút "..." → Remove Script riêng để gỡ đúng script đó. Sửa lúc Edit lưu cùng scene; sửa lúc đang Play chỉ ảnh hưởng object đang sống, mất khi Stop.

Scene (panel edit)

Hai pane song song Top/Bottom, mỗi pane một camera tự do (pan/zoom/orbit) độc lập với camera thật trong scene — không bao giờ sửa CameraComponent khi chỉ đang thao tác xem, giống Unity's Scene-vs-Game. Nút 2D | 3D mỗi pane chuyển pipeline render.

Chế độThao tác chuột
2DKéo-giữa (middle-drag) pan, lăn chuột zoom, click trái chọn sprite/kéo gizmo.
3DClick/kéo trái chọn + kéo gizmo, kéo phải orbit (quaternion thật, không giới hạn gimbal-lock), kéo-giữa pan, lăn chuột zoom.

Cả hai chế độ vẽ lưới kiểu Unity/Cocos (xem Rendering) và khung frustum thật cho camera entity thay vì chấm phẳng. Nút Translate / Rotate / Scale đổi chế độ gizmo cho entity đang chọn — kéo handle sửa Transform trực tiếp, thấy ngay ở cả Scene, Game, và bản build 3DS thật. Transform.Rotation luôn tính bằng độ.

Entity inactive (checkbox Active tắt) biến mất khỏi cả hai pane Scene ngay lập tức, giống Game view — không chỉ mờ đi như quy ước gốc của Unity. Collider/frustum camera/gizmo vẫn hiện để còn chỉnh sửa được entity đó trong lúc inactive.

Game

Vẽ đúng những gì camera TopCamera/BottomCamera thật render, xếp chồng theo đúng bố cục vật lý máy (Top trên, Bottom dưới) — cùng render pass 3DS thật dùng. Play/Stop chạy toàn bộ vòng đời runtime (script, physics 2D/3D, sự kiện va chạm/trigger, UI); Stop phục hồi đúng trạng thái trước khi Play (xem Kiến trúc). Reload Scripts build lại GameScripts trên một thread nền (không đứng hình Editor lúc build) rồi hot-load vào Editor đang chạy mà không khởi động lại — nút tự đổi thành "Reload Scripts (reloading...)" và bị disable trong lúc build đang chạy. Reconfigure (cmake -B) chạy trước build mỗi lần — cần thiết để nhặt được script project vừa tạo (hoặc project vừa đổi), không chỉ file đã sửa; File → Open Project.../ New Project... cũng tự kích hoạt bước reload này, không cần bấm tay.

Click/chạm vào ảnh mỗi màn ở đây (lúc đang Play) được resolve đúng về toạ độ pixel local của màn đó — Behaviour::GetPointerPosition()/ScreenPointToRay3D hoạt động y hệt Play-in-Editor như trên DualityPlayerDesktop hay 3DS thật.

Console

Xem log Duality::Log (kể cả Behaviour::LogInfo/Warn/Error từ script), tô màu theo mức (Trace/Info/Warn/Error), lọc theo mức + ô tìm kiếm text.

Content Browser

Xem chi tiết ở Asset Pipeline — gồm cả menu Create → Script để thêm script riêng cho project đang mở.

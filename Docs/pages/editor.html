API Reference

Editor Panels

Editor desktop dựng bằng Dear ImGui, hành vi và giao diện theo Unity: skin tối kiểu Unity (font Segoe UI của Windows, icon Font Awesome), layout mặc định Hierarchy trái · Scene/Game giữa · Inspector phải · Project/Console dưới, toolbar chính dưới menu (tool Q W E R T, Pivot/Center, Global/Local, snap; nút Play/Pause/Step ở giữa; Layout bên phải). Khi khởi động mở project SampleProject/ (hoặc --project <file.dproj>), đổi project qua File → Open Project... / Open Recent Project.

Layout & cửa sổ

Tên cửa sổ theo Unity: Hierarchy, Scene, Game, Inspector, Project (trước đây là "Content Browser" — imgui.ini cũ được tự đổi tên nên layout đã lưu không mất), Console, Lighting. Layout dock được lưu trong imgui.ini và khôi phục lần sau; chỉ khi chưa có layout lưu (hoặc chọn Window → Layouts → Reset All Layouts / nút Layout ▾ trên toolbar) editor mới dựng lại layout mặc định. Đóng một cửa sổ bằng nút ×, mở lại qua Window → General. Tiêu đề cửa sổ OS: DualityEditor - <Project> - <Scene>* (* = còn thay đổi chưa lưu, kèm [Playing]/[Paused]). Theme: Edit → Preferences → Color Theme (Unity Dark mặc định, còn Blue / Pink / Dark).

Undo / Redo & scene dirty

Mọi thay đổi scene đều undo được: sửa field Inspector, kéo gizmo / handle collider / UI rect, tạo / xoá / duplicate / paste / reparent / đổi thứ tự, thêm / xoá / reset / paste component, bật-tắt active, thao tác prefab. Mỗi tương tác là một bước: cả một lần kéo slider hay kéo gizmo, cả một lần gõ tên (bước được chốt khi thả chuột / rời ô text). Menu Edit hiện tên bước ("Undo Move", "Redo Add Rigidbody 2D"...). Undo/Redo khôi phục luôn selection và trạng thái mở/đóng của Hierarchy nhờ ID ổn định của entity (chỉ nằm trong bộ nhớ editor, không ghi vào file scene). Lịch sử giữ tối đa 128 bước. Thay đổi lúc Play không vào lịch sử và bị hoàn tác khi Stop.

Scene có thay đổi chưa lưu hiện * ở tiêu đề cửa sổ, menu bar và dòng scene của Hierarchy. Mở scene khác, New Scene, mở/tạo project, thoát editor khi scene đang dirty đều hỏi kiểu Unity: Save / Don't Save / Cancel.

Build Settings

Cửa sổ nổi (không dock vào layout chính), mở qua File → Build Settings.... Danh sách Scenes In Build ở trên — dòng trên cùng luôn đánh dấu [Main], đây chính là Start Scene lúc chạy bản build thật. Kéo một dòng lên/xuống để đổi chỗ với dòng liền kề (đổi thứ tự), nút x cuối dòng để gỡ khỏi danh sách. Bên dưới là Other Scenes In Project — quét lại mọi file .scene trong Assets/ của project mỗi lần cửa sổ render (trừ scene đã có ở danh sách trên), click một tên để thêm vào Scenes In Build. Mọi thay đổi (thêm/gỡ/đổi thứ tự) lưu project ngay lập tức, không cần Save riêng.

Cuối cửa sổ là nút Build for 3DS — chạy đúng pipeline build như mục File → Build for 3DS (xem Build & Deploy), tiện chỉnh xong danh sách scene rồi build luôn không cần đóng cửa sổ này. Thanh tiến trình bên dưới không có mốc phần trăm thật — build 3DS không có bước nào đếm được — nên lúc build đang chạy nó chỉ dao động qua lại làm tín hiệu "vẫn đang chạy", xong hiện chữ xanh Build succeeded hoặc đỏ Build failed (xem Console để biết chi tiết lỗi).

Project Settings

Mở qua Edit → Project Settings.... Hiện Name/Assets Directory/Scripts Directory của project đang mở — chỉ đọc ở phiên bản đầu này, chưa cho sửa trực tiếp: đổi những đường dẫn này lúc project đang chạy sẽ làm lệch (desync) mọi asset/script path đã resolve từ trước đó. Đây là điểm khởi đầu để phát triển thêm dần, chưa phải bản đầy đủ.

Mục Icon (3DS) ngay dưới — khác với 3 field phía trên, đây là field được sửa trực tiếp ở đây: xem preview ảnh (48×48) rồi bấm Browse... chọn một file PNG bất kỳ làm icon cho bản build .cia. Đường dẫn lưu vào ProjectConfig::IconPath của project (không phải EditorSettings — icon gắn với project, không phải máy), đi xuyên suốt File → Build for 3DS/nút Build trong Build Settings ở trên vào đúng bước bannertool makesmdh đã có sẵn (xem Build & Deploy) — không chỉnh gì cũng vẫn build được, rơi về icon placeholder có sẵn của engine như trước giờ. Chỉ áp dụng cho bản 3DS — icon file .exe desktop cần cơ chế hoàn toàn khác (.ico + resource script biên dịch kèm), chưa làm ở đây.

Preferences

Mở qua Edit → Preferences... — cấu hình cấp Editor, dùng chung cho mọi project trên máy (khác Project Settings ở mục trên, vốn gắn riêng theo từng .dproj) — lưu một lần tại %APPDATA%\DualityEngine\EditorSettings.json, không nằm trong file .dproj của bất kỳ project nào. Trường External Editor trỏ tới một file thực thi (vd code.exe của VS Code) — nút Browse... mở dialog chọn file thật, nút Open Project in External Editor chạy <external editor> "<thư mục project>" cho project đang mở.

Hierarchy

Cây cha-con của scene, hàng đầu là chính scene (tên + * khi dirty, chuột phải: Save/Save As/Paste/Create). Click chọn, Ctrl+click thêm/bớt, Shift+click chọn dải; kéo một object đang nằm trong selection là kéo cả selection. Thả lên ¼ trên/dưới của một dòng để chèn trước/sau (thả ¼ dưới của node đang mở = thành con đầu tiên), thả giữa dòng để làm con; thả vào khoảng trống = về gốc scene; thả asset .prefab = tạo instance. Alt+click mũi tên mở/đóng cả nhánh. Object chọn từ Scene view / field tham chiếu được tự mở cha và cuộn tới. Object inactive hiện mờ; nút mắt ở mép phải mỗi dòng bật/tắt Active (áp dụng cho cả selection). Prefab instance tô xanh kiểu Unity (đỏ nếu asset mất). F2 / Enter đổi tên tại chỗ; double-click = Frame Selected trong Scene. Chuột phải một dòng: Cut/Copy/Paste/Paste As Child/Rename/Duplicate/Delete, Select Children, Expand/Collapse All, Create Empty Parent, Prefab (Create / Open / Select Asset / Unpack) và toàn bộ menu GameObject để tạo con.

Inspector

Đầu Inspector là header GameObject kiểu Unity: checkbox Active, ô tên, nút khoá (🔒 = Lock, ghim Inspector vào selection hiện tại), dòng Tag (danh sách tag có sẵn + "Add Tag") và Layer (Inherit / Default / TOP / BOTTOM — tương ứng LayerComponent), rồi dòng Prefab (Open = Prefab Mode, Select = ping asset, Overrides ▾ = số giá trị khác prefab, Revert All / Apply All / Unpack).

Mỗi component là một thẻ: mũi tên gập, icon, checkbox Enabled (nếu có), tên đậm, nút ⋮ (hoặc chuột phải header): Reset, Remove Component, Move Up/Down (cho script; component có sẵn giữ thứ tự cố định), Copy Component, Paste Component Values, Paste Component As New, và với script thêm Edit Script (mở file bằng external editor trong Preferences). Field theo kiểu Unity: nhãn bên trái (kéo ngang nhãn số để "scrub" giá trị), vector dạng X [ ] Y [ ] Z [ ], màu là ô màu + ô hex (RRGGBB(AA)), asset / entity là object field có icon/thumbnail: click = ping trong Project / Hierarchy, double-click = chọn, kéo-thả để gán, nút ◎ mở bộ chọn có tìm kiếm, chuột phải = Clear. List hiện dạng Element 0..n với nút + / −.

Chọn nhiều object: chỉ hiện component mà tất cả cùng có; giá trị khác nhau hiện "—" (từng thành phần X/Y/Z riêng); sửa một lần áp dụng cho tất cả và là một bước Undo (sửa X chỉ đổi X, Y/Z của từng object giữ nguyên). Script chỉnh từng object một.

Prefab override: trên instance, field khác giá trị trong file .prefab hiện chữ đậm + vạch xanh bên trái; chuột phải nhãn → Revert. Component thêm vào instance có "(+)" ở header. (Vị trí / góc quay của root không tính là override, như Unity.)

Add Component: popup tìm kiếm theo nhóm (drill-down như Unity): Rendering, Effects, Animation, Physics 2D, Physics, Audio, UI, Camera, Miscellaneous, Scripts (mỗi class ghi (C++) hoặc (TS)) và New Script — gõ tên, chọn TypeScript hoặc C++, "Create and Add" tạo file trong Assets/Scripts/ và gắn ngay (TypeScript tự biên dịch; C++ cần Reload Scripts). Gõ tên chưa tồn tại trong ô tìm kiếm cũng có mục "New script '...'" . Kéo file script từ Project thả vào Inspector cũng thêm script đó.

Field DUALITY_PROPERTY (C++), @field (TypeScript) và field component có sẵn dùng chung bộ vẽ field này. Sửa lúc Edit lưu cùng scene; sửa lúc Play chỉ ảnh hưởng object đang sống, mất khi Stop. Khi chọn asset trong Project, Inspector hiện inspector riêng của loại asset đó.

Scene

Hai pane Top/Bottom (kéo thanh chia ở giữa để đổi tỉ lệ, double-click để về 50/50), mỗi pane một camera editor riêng. Điều khiển camera giống PiaEngine / Unity (quy tắc nằm trong DualityEditor/Source/SceneView/SceneViewNavigation.cpp, có unit test). Thanh công cụ của mỗi pane: 2D | 3D, Grid, Gizmos (ẩn/hiện icon component, collider, handle), nhãn pipeline (3D · citro3d / 2D · citro2d, rê chuột để xem phím điều khiển). Góc trái trên mỗi pane có cột công cụ nổi (Hand / Move / Rotate / Scale / Rect, công cụ hiện tại được tô sáng); góc phải trên pane 3D có axis gizmo. Camera Scene view của từng scene được nhớ trong <Project>/Library/SceneViewState.json (không ghi vào file scene).

Game & Play mode

Nút Play / Pause / Step ở giữa toolbar (Ctrl+P, Ctrl+Shift+P, Ctrl+Alt+P). Khi Play cả editor phủ màu đỏ nhạt (play-mode tint) để nhắc rằng thay đổi lúc này sẽ mất. Pause dừng game (Scene/Inspector vẫn dùng được); Step chạy đúng một frame cố định 1/60s (bấm Step khi chưa Play = vào Play ở trạng thái Pause). Stop khôi phục đúng scene trước Play và giữ nguyên selection. Panel Game vẽ đúng những gì camera thật render (Top trên, Bottom dưới), có Reload Scripts (build lại GameScripts ở thread nền) và thống kê render. Click vào ảnh mỗi màn lúc Play được quy đổi đúng về toạ độ pixel của màn đó. UI rect kéo/resize trực tiếp trong Game view (có Undo).

Console

Toolbar kiểu Unity: Clear, Collapse (gộp dòng trùng, hiện số lần), Clear on Play, Error Pause (lỗi mới lúc Play → tự Pause), ô tìm kiếm và ba nút lọc Info/Warning/Error kèm số lượng. Click một dòng để xem toàn văn ở khung chi tiết bên dưới (kéo thanh chia để đổi chiều cao, chọn/copy được); chuột phải → Copy.

Project

Hai cột: cây thư mục (Assets, Packages) bên trái và lưới asset bên phải. Thanh trên: nút + ▾ (Create: Folder, C++ Script, TypeScript Script, Scene, Material, ScriptableObject), breadcrumb bấm được (Assets › Folder › ..., thả asset lên để di chuyển) và ô tìm kiếm (tìm trong mọi thư mục con). Thanh dưới: đường dẫn asset đang chọn và thanh trượt cỡ icon (hoặc Ctrl+lăn chuột). Chuột phải asset: Open, Show in Explorer, Copy Path, Rename (F2), Duplicate (Ctrl+D), Delete; chuột phải khoảng trống: Create, Show in Explorer, Refresh. Kéo một object từ Hierarchy thả vào lưới để tạo prefab ở thư mục đang xem. Field asset trong Inspector "ping" asset ở đây (mở đúng thư mục, viền vàng nhấp nháy). Chi tiết pipeline asset: Asset Pipeline. Texture ở Sprite Mode Multiple có mũi tên mở ra các sprite con (như Unity): mỗi sprite là một ô có thumbnail đúng vùng cắt, kéo được vào field sprite, vào Scene (tạo SpriteRenderer với kích thước gốc) hoặc vào Hierarchy. Ping một texture đã cắt sẽ tự mở danh sách sprite của nó.

Sprite Editor

Mở qua Window → 2D → Sprite Editor hoặc nút Sprite Editor trong Inspector của texture (Inspector có thêm Sprite Mode Single/Multiple và Pixels Per Unit; 0 = PPU của project). Cửa sổ đi theo texture đang chọn trong Project. Vùng giữa là texture trên nền ô bàn cờ: lăn chuột zoom quanh con trỏ, chuột giữa (hoặc Alt + kéo trái) để pan, F để vừa khung.

Cắt lại theo lưới giữ nguyên id của sprite trùng tên nên các tham chiếu cũ không bị gãy. Hộp Sprite góc dưới phải: Name, Position, Size, Border (L T R B), Pivot (preset + Custom). Đóng cửa sổ / đổi texture khi còn thay đổi chưa Apply sẽ hỏi Apply / Revert. Single mode chỉnh pivot + border của cả texture.

Dữ liệu nằm trong .meta của texture (khối Importer: SpriteMode, PixelsPerUnit, TextureSize, SpritePivot/SpriteBorder, Sprites[] với Id, Name, Rect (px, gốc trên-trái), Pivot, Border); texture chưa từng dùng sprite giữ nguyên .meta cũ. Field asset tham chiếu một sprite bằng "<guid texture>#<id sprite>"; GUID trơn vẫn là cả texture. Dùng được ở SpriteRenderer (thêm Draw Mode Simple/Sliced; pivot của sprite thay cho Pivot của renderer), UI Image (border của sprite tự cắt 9-slice khi Slice Border = 0), Sprite Flipbook, Sprite Sheet Animator (texture Multiple chạy lần lượt các sprite thay cho lưới Columns × Rows), Particle System và tileset của Tilemap.

Animation

Window → Animation → Animation (Ctrl+6). Làm việc với clip của Animation component trên object đang chọn (hoặc cha gần nhất có Animation; nút khoá để giữ object). Object chưa có clip: nút Create tạo Assets/Animations/<Tên>.anim và gắn Animation component.

PhầnHành vi

Preview (bật tự động khi scrub/play/record): giá trị lấy mẫu được ghi vào scene đang mở để xem trong Scene/Game nhưng không làm scene dirty; tắt Preview, đổi object, Play, Save, Undo đều trả lại giá trị gốc trước (Save không bao giờ lưu tư thế đang preview). Tile Palette

Window → 2D → Tile Palette. Active Tilemap đi theo object Tilemap đang chọn (hoặc chọn trong danh sách). Palette là các sprite của texture Tileset (cắt bằng Sprite Editor), xếp đúng vị trí trên sheet; click một ô = brush 1 tile, kéo một hình chữ nhật = brush nhiều tile. Chỉ số tile trong .tilemap là chỉ số sprite trong danh sách sprite của tileset (tileset chưa cắt: cả texture cho mọi ô như trước).

Profiler

Window → Analysis → Profiler (Ctrl+7). Ghi khi cửa sổ mở (ô Record), tối đa 300 frame; bấm Play để có số liệu của game. Biểu đồ CPU Usage xếp chồng theo nhóm (Rendering, Scripts, Physics, Animation, UI, Editor, Others; mốc 60/30 FPS), click để chọn frame; Rendering / Memory: đồ thị một bộ đếm (Draw Calls, Sprites, Mesh Draw Calls, Visible Meshes, Texture Memory (KB), JS Heap (KB), Entities) và giá trị của frame đang chọn; Hierarchy: cây marker gộp theo tên với Total/Self (%), Calls, Time/Self ms.

Marker engine (DUALITY_PROFILE_SCOPE, DualityEngine/Core/Profiler.h): PlayerLoop, UI.Events, Physics.FixedStep, Scripts.C++ / Scripts.TypeScript (từng callback), Scene.RuntimeSystems, Animation.Sample, Render.Game, Render.3D, Render.2D, Render2D.Tilemap, Render.UI, Editor.Panels. Khi không ghi, mỗi marker chỉ là một phép so sánh bool; trên bản 3DS chúng bị loại hẳn khi biên dịch.

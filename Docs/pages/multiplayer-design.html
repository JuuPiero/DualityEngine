Multiplayer & Nintendo 3DS Network

Bản thiết kế cho local wireless và online multiplayer của DualityEngine. Trang này chốt ranh giới module, protocol và lộ trình trước khi runtime có bất kỳ transport nào.

Trạng thái hiện tại Engine chưa có transport, lobby, replication hay Network component. Chỉ lifecycle portable OnApplicationFocus, OnApplicationPause, OnApplicationQuit đã có để game xử lý HOME/gập máy/wake/exit. Tất cả class có chữ “proposed” là thiết kế, chưa phải API gọi được.

Nguyên tắc

  • Gameplay không biết UDS hay socket. Script chỉ biết session, peer, message và state game.
  • Local-first. UDS là milestone đầu cho multiplayer gần nhau trên 3DS; online là transport khác.
  • Host authoritative. Client gửi input/intent; host quyết định state, hit, spawn và score.
  • Không gửi raw ECS. Không truyền entt::entity, pointer, layout của std::string hoặc memcpy struct C++.
  • Không block frame. Scan, receive, reconnect là poll/tick có packet budget.
  • Desktop test được. Cùng session/codec phải chạy Loopback hoặc UDP desktop trước khi test hai máy.

UDS local wireless

UDS dành cho thiết bị 3DS ở gần nhau. Host tạo lobby; client scan beacon và join. Nó không phải internet API và không thay UDP. Lobby cần protocol version, build/content hash, player limit và room name trong beacon/application data.

UDP / online

Online không dùng UDS. Trên 3DS, UdpTransport sở hữu buffer aligned cho socInit và dùng BSD UDP non-blocking; desktop dùng transport tương đương. NAT traversal, relay, account/authentication và matchmaking server là một dịch vụ riêng, không phải vài hàm engine.

  • Milestone online đầu: direct IP/LAN UDP để kiểm chứng codec và simulation.
  • UDP không tự reliable: session bổ sung sequence, ack bitmask, resend timeout và ordering theo channel khi cần.
  • Game cạnh tranh không tin client: host/relay phải authoritative với input và state quan trọng.

Protocol và serialization

// wire-format concept — encode từng field, không memcpy
magic:u16 | protocolVersion:u8 | channel:u8 | sessionId:u16 |
sequence:u16 | ack:u16 | ackBits:u32 | payloadLength:u16 | payload:bytes
  • Unreliable sequenced: input mới nhất, transform snapshot; packet cũ bị bỏ.
  • Reliable ordered: lobby, spawn/despawn, inventory, scene transition.
  • Version gate: từ chối protocol/build/content hash không tương thích trước gameplay packet.
  • Budget: hard cap size/packet/frame; reject length sai trước allocation và parse.

Replication: gửi input, không gửi Transform

Với platformer/physics, client gửi input command kèm tick. Host validate và simulate, sau đó gửi snapshot. Client nội suy remote entity; client prediction/reconciliation chỉ thêm sau khi loop cơ bản ổn định.

HOME, sleep và reconnect

DualityPlayer đã bridge APT suspend/sleep, restore/wake và exit thành lifecycle portable. NetworkSession subscribe tại runtime layer, không để từng script tự đóng UDS/socket.

  1. OnApplicationPause(true): dừng gửi input, mark session suspended, flush save/checkpoint nếu cần.
  2. Transport đóng hoặc đánh dấu connection stale; không block chờ network.
  3. OnApplicationPause(false): rescan/reconnect qua state machine; chỉ resume khi host xác nhận.
  4. OnApplicationQuit(): leave best-effort rồi cleanup idempotent.

Lobby state machine

Offline
  ├─ Host() ───────────────► Hosting ─► InGame ─► Leaving ─► Offline
  └─ Scan() ─► Discovering ─► Joining ─► Lobby ─► InGame
                         │        │          │
                         └────────┴──────────┴── error/timeout ─► Offline

Suspended là overlay state: transport không gửi gameplay packet tới khi reconnect.

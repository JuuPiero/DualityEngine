API Reference

API Stack — từ thấp đến cao

Sơ đồ tham chiếu nhanh mọi lớp API trong repo — đọc từ dưới lên trên (runtime lõi → gameplay script). Mỗi mục trỏ tới trang chi tiết hoặc header source.

Nguyên tắc phụ thuộc GameScripts trên desktop chỉ include header của DualityEngine, không link compiled code — mọi lời gọi chạm subsystem runtime (Input, physics, audio…) đi qua EngineServices hoặc wrapper trong Scripting/.

Tính năng mới (phiên bản gần đây)

  • Component mở rộng: Capsule/Polygon collider 2D, Capsule 3D, PhysicsMaterial (.physmat), Canvas/Layout/UI widgets, Tilemap, LineRenderer, FollowTarget, ParticleSystem CPU, Sprite sort/flip/9-slice.
  • Script wrappers: Transform, Rigidbody2D/3D, Collider2D/3D, EntityLayer, UI widgets — xem Behaviour.h.
  • DUALITY_PROPERTY enum: enum class tự định nghĩa → Combo; engine enum (Layer, BodyType) → Combo sẵn.
  • Scene gizmo: Transform gizmo cho mọi entity (kể cả empty); collider resize không cần bật EditMode; picking qua collider/pivot.
  • Scene dirty + Ctrl+S: Dấu * trên menu bar khi có thay đổi chưa lưu.
  • LayerComponent::Value — field serialize "Layer" (tránh trùng tên enum trên toolchain 3DS).

TypeScript Scripting (QuickJS)

Ngoài C++ (Behaviour), gameplay script còn viết được bằng TypeScript với API giống Unity/PiaEngine (MonoBehaviour, getComponent, @field...), chạy trên trình thông dịch QuickJS-ng nhúng trong engine — cùng một bundle chạy trong Editor, DualityPlayerDesktop và trên 3DS (dạng bytecode). Script TS và C++ gắn chung một entity, hiện chung trong Add Component, lưu chung định dạng scene JSON và đi qua đúng cùng vòng đời của Scene.

Script đầu tiên

Content Browser → chuột phải → Create > TypeScript Script. Mỗi class export kế thừa MonoBehaviour là một script (tên = tên export).

import { MonoBehaviour, Time, Input, KeyCode, Prefab, field } from 'duality';

export class Rotator extends MonoBehaviour {
  @field({ range: [0, 720] }) degreesPerSecond = 90;  // slider
  @field(Prefab) effect: Prefab | null = null;            // kéo .prefab vào
  clockwise = true;                                    // field public: tự hiện + tự lưu

  update() {
    this.transform.rotate(0, 0, (this.clockwise ? 1 : -1) * this.degreesPerSecond * Time.deltaTime);
    if (Input.getKeyDown(KeyCode.GamepadA) && this.effect) this.instantiate(this.effect);
  }
}

Lưu file là đủ: Editor theo dõi Assets/**/*.ts, biên dịch nền (esbuild + kiểm tra kiểu TypeScript) và nạp lại; lỗi hiện trong Console dạng Assets/Rotator.ts:12:5: error: .... Đổi script trong lúc Play thì bản mới được nạp khi bấm Stop. Cần cài Node.js (node trong PATH) cho Editor; game đã build không cần.

Build & chạy

Nơi chạyCách nạp script
Editornode Tools/TypeScript/build-scripts.mjs <project> --typecheck chạy tự động → <project>/Library/ScriptAssemblies/scripts.js + .map
DualityPlayerDesktopNạp Library/ScriptAssemblies/scripts.js của project (--scene TypeScriptDemo/TypeScriptDemo.scene để chạy demo)
3DSBuild for 3DS: bundle release (minify) → DualityJsc → romfs:/Scripts/scripts.jsbc (bytecode QuickJS, không tốn parser lúc boot) + scripts.js dự phòng + .map (chỉ đọc khi có lỗi)
Bộ nhớ trên 3DS Một runtime QuickJS cho cả game: giới hạn heap 8 MB, ngưỡng GC 512 KB, stack 192 KB (JsRuntimeOptions::PlatformDefault). Scene demo dùng khoảng 0,25–0,3 MB heap trên 3DS (đo trong Citra; bundle 39 KB JS / 61 KB bytecode, nạp ~80 ms). Mã máy QuickJS thêm khoảng 0,85 MB vào file .3dsx.
Lỗi runtime (exception) được log kèm file:dòng TypeScript và chỉ tắt script bị lỗi trong lần Play đó. Vòng lặp vô hạn bị watchdog ngắt sau 3 s (desktop) / 5 s (3DS).

Nintendo 3DS-first C++ game engine

DualityEngine Documentation

Tài liệu cho runtime, editor và pipeline build của DualityEngine. Engine chạy trên Windows để edit/hot-reload và Nintendo 3DS qua devkitPro, với hai màn hình, touch input, 2D/3D renderer và package gameplay.

Điểm bắt đầu khi viết game Dùng Behaviour làm script, Transform(GetEntity()) để thay đổi transform, wrapper như SpriteRenderer/Rigidbody2D/LineRenderer cho component, và Input cho nút/touch. Toàn bộ declaration xem ở API Reference.

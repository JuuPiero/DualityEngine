DualityEngine · Tài liệu kỹ thuật

Engine C++ tự viết cho Nintendo 3DS

DualityEngine là một game engine + editor viết bằng C++, nhắm tới Nintendo 3DS (devkitARM/devkitPro) và desktop Windows. Trang này là tài liệu tham khảo đầy đủ cho mọi hệ thống engine hiện có — từ tổng quan kiến trúc tới chữ ký từng API, sắp xếp từ cao xuống thấp.

Bắt đầu từ đâu?

⚙️
Cài đặt & Build
Cài devkitPro, build Editor trên desktop, build/chạy trên 3DS thật hoặc Citra.
 🎮
Làm game đầu tiên
Hướng dẫn từng bước: tạo scene, thêm vật lý, viết script, dựng UI, chuyển scene, build ra máy thật.
 🧩
Kiến trúc: ECS & Scene
Entity/Component/Scene, hệ thống Reflection, vòng đời Play/Stop, cách engine tổ chức dữ liệu.

Tài liệu API theo hệ thống

📜
Scripting API
Behaviour: vòng đời, Input, Physics, Audio, Raycast, DUALITY_PROPERTIES, EntityRef, SceneManager.
 🪐
Physics 2D/3D
Rigidbody, Collider, BodyType, Collision/Trigger events, Raycast2D/3D (Box2D + Bullet).
 🖼️
Rendering & UI
Renderer 2D/3D, Camera, Material/Mesh, hệ UI trong game (Panel/Button).
 📦
Asset Pipeline
GUID/.meta, Prefab, ScriptableObject, Texture/Audio Import Settings, AssetDatabase.
 🛠️
Editor Panels
Hierarchy, Properties, Scene, Game, Content Browser, Console, Menu Bar.
 🚀
Build & Deploy
Build for 3DS/PC, đóng gói .3dsx/.cia, cấu trúc project/romfs.

Engine gồm những gì?

Thành phầnMô tả
DualityEngineThư viện lõi dùng chung: ECS (EnTT), Reflection, Scene, physics 2D (Box2D) + 3D (Bullet), renderer interface + backend OpenGL/citro2d/citro3d, hệ UI, asset pipeline, scripting registry.
DualityEditorEditor desktop (Dear ImGui) — toàn bộ panel, gizmo, build pipeline, asset inspector.
DualityPlayerRuntime thực thi trên 3DS — link tĩnh với GameScripts, không có UI editor.
DualityPlayerDesktopRuntime desktop độc lập (không Editor) — cùng pipeline Scene/Renderer với 3DS.
GameScriptsCode gameplay (Behaviour subclass) — build DLL hot-reload trên desktop, link tĩnh trên 3DS, cùng một bộ source.
Về tài liệu này Mọi API mô tả ở đây phản ánh code thực tế trong repo tại thời điểm viết. Nếu thấy sai lệch với source, source luôn là nguồn đúng — hãy đối chiếu đường dẫn file ghi kèm mỗi mục API.
